# hdtextures

Единая папка замен текстур для нашей VCS US.

**2130 игровых назначений, 1959 PNG, 152.85 МиБ.** Последнее дополнение: 1513 назначений для оригиналов PC Vice City; все 617 прежних назначений и 528 PNG сохранены.

1952 PNG используются манифестом; 7 прежних файлов сохранены без подтверждённых назначений. В наборе есть авторские HD-замены и более качественные оригиналы других платформ. Не все изображения являются современными HD-перерисовками.

Новые 1431 PC-файлов находятся в `Assets/World/PCOriginals/`. PNG скопированы без изменения байтов, размеров, RGB или alpha. Каждая новая замена как минимум вдвое больше PSP-оригинала по обеим сторонам. Существующие HD-назначения имеют приоритет и не заменялись. Новые AI-текстуры и исправления alpha не добавлялись.

В выявленном инвентаре 6567 уникальных исходных изображений; замены есть для **2118 (32.25%)**, до этого дополнения — 605 (9.21%). Это не гарантированно полный перечень всех динамических текстур. Mipmap и точные дубликаты не считаются отдельно; самостоятельные LOD- и цветовые варианты считаются отдельно. [Полный подсчёт](Sources/PCOriginals/coverage.json).

`textures.ini` использует `hash = quick`. Для дополнения проверены все 1513 ключей по текущим игровым данным, исходные RGBA, source SHA256/Git blob SHA1, совместимость alpha, пути PNG и отсутствие wildcard-конфликтов. Игрового прогона этого дополнения не было; Steam Deck не обновлялся.

Старый неполный список пробелов: закрыты 69 из 418, остаются 349. Этот список не описывает полное покрытие игры. Технические сводки: `summary.json`, `verification.json`, `checksums.sha256`. Исторические результаты прежних добавлений сохранены внутри сводок и `Sources/`.
