# Original PC Vice City textures

Источник: [ASI-Factory/GTA-VCS-Texture-Pack-PSP, source/FromPC](https://github.com/ASI-Factory/GTA-VCS-Texture-Pack-PSP/tree/d4524c33e47a73d6c6661bce90968f241bdea486/source/FromPC), commit `d4524c33e47a73d6c6661bce90968f241bdea486`. Это оригинальные материалы **GTA: Vice City для PC**, собранные автором пакета; права на игровые изображения остаются у их правообладателей. Это не AI-апскейл и не современная HD-перерисовка.

Архив исходного репозитория: SHA256 `7bc450c116d68c78390b7ad770b14517905b4ff2e0de4b2ada0a02c0dce7893f`. Извлечены все 11893 PNG (6328 уникальных RGBA); каждый PNG сверён с Git blob SHA1 указанного коммита. Исполняемые файлы не запускались.

В набор добавлены **1513 назначений для 1513 ранее непокрытых оригинальных изображений**, использующие **1431 PNG**. Все прежние 617 назначений и 528 PNG сохранены. Одинаковое PC-изображение для нескольких PSP-вариантов хранится один раз.

Все новые PNG скопированы **побайтово** из PC-источника. Размеры, RGB и alpha не изменялись. Исходные PC-текстуры обычно имеют размер 64–256 пикселей; в набор входят и более чёткие LOD-текстуры размером 32×32. Каждая замена как минимум вдвое больше PSP-оригинала по обеим сторонам. Они повышают детализацию по сравнению с PSP, но не делают все поверхности современными 2K/4K-материалами.

Поиск включал именованные и безымянные игровые текстуры. Кандидаты проверены по соотношению сторон, структуре, границам и цветам. Из 1558 лучших кандидатов 45 исключены после визуальной проверки: неверные цвета, несовпадающие детали, слишком гладкие неопределимые поверхности. 1053 принятых пар просмотрены на сравнительных листах; остальные 460 прошли строгий численный фильтр, группа дополнительно проверена выборочно. Листы и воспроизводящие скрипты находятся в `work/original-texture-import/`.

Для непрозрачных PSP-оригиналов допустимы только непрозрачные PC-источники (alpha не ниже 254). Для семи остальных изображений проверены маски прозрачности после уменьшения к исходному размеру: средняя ошибка alpha ≤ 8/255, доля сильных отличий ≤ 2%, сохранность прозрачной и непрозрачной внутренней области; все семь просмотрены визуально. Alpha не восстанавливалась и не исправлялась.

Все 1513 новых native quick-ключей повторно вычислены из **текущих файлов VCS US**. Декодированные исходные игровые RGBA совпали с эталонами сравнения. Новые ключи не пересекаются с прежними или друг с другом, включая wildcard-поля. Игровые данные, код, настройки и сохранения не изменялись.

В текущем инвентаре выявлено **6567 уникальных исходных изображений**. Покрытие заменами выросло с **605 (9.21%)** до **2118 (32.25%)**. Уровни mipmap и точные дубликаты не считаются отдельно; самостоятельные LOD- и цветовые варианты считаются отдельно. Это охват выявленного инвентаря, а не доказательство обнаружения абсолютно всех динамических текстур. 11 старых активных ключей пока не сопоставлены с этим инвентарём.

Игрового прогона этого дополнения не было; Steam Deck не обновлялся. Внешний вид и прозрачность в конкретных игровых сценах ещё требуют проверки. Новые PS2-материалы не добавлялись: оригинальный образ VCS PS2 не предоставлен. Установленные ранее источники PS2 и AI сохранены без изменений; новых AI-текстур нет.

- `selected.json` — точные PSP → PC соответствия, источники, размеры, хеши и метрики.
- `original-verification.json` — повторная проверка текущих игровых байтов и ключей.
- `rejected.json` и `review-decisions.json` — причины отказа и просмотренные листы.
- `source-summary.json`, `merge-result.json`, `coverage.json` — сводки источника, импорта и покрытия.
